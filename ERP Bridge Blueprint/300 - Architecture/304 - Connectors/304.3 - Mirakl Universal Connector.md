## 1. Propósito y Descubrimiento Estratégico

Al analizar el ecosistema de marketplaces en España, se identificó que la mayoría de los líderes del retail físico y vertical comparten la misma plataforma tecnológica subyacente:

> **Leroy Merlin, PcComponentes, Carrefour España, MediaMarkt, Decathlon, Worten, Brico Depôt y El Corte Inglés operan sobre la plataforma MIRAKL.**

### La Ventaja Arquitectónica de ERP Bridge:
En lugar de desarrollar 6 o 7 conectores independientes con APIs dispersas, ERP Bridge implementa un **único conector universal parametrizable (`MiraklConnector`)**. 

Cualquiera de estos marketplaces se activa simplemente indicando en la configuración:
* `endpointUrl`: URL del operador (ej. `https://leroymerlin-prod.mirakl.net/api` o `https://pccomponentes-prod.mirakl.net/api`).
* `apiKey`: Clave de API de vendedor generada en el panel de Mirakl del cliente.

---

## 2. Capacidades de la API de Mirakl

Mirakl expone una API REST moderna, predecible y de alto rendimiento basada en JSON:

### 2.1 Sincronización de Ofertas (Precios y Stock)
* **Endpoint:** `POST /api/offers`
* **Formato:** Carga síncrona o asíncrona de ofertas en JSON:
  ```json
  {
    "offers": [
      {
        "sku": "FERR-4012",
        "product_id": "8435123456789",
        "product_id_type": "EAN",
        "price": 24.50,
        "quantity": 18,
        "state_code": "11"
      }
    ]
  }
  ```
* **Rendimiento:** Permite actualizar cientos de referencias en un único payload, ideal para el motor de Delta Sync de ERP Bridge.

### 2.2 Gestión y Descarga de Pedidos
* **Endpoint:** `GET /api/orders`
* **Filtros:** `order_state_codes=WAITING_ACCEPTANCE,SHIPPING` y `start_date=<last_sync_timestamp>`.
* **Flujo Operativo:**
  1. ERP Bridge recupera los pedidos pendientes de aceptar.
  2. Confirma la aceptación del pedido mediante `PUT /api/orders/{order_id}/accept`.
  3. Inserta el pedido en Factusol en `F_PCL` con referencia inmutable:
     `REFPCL = 'MRK-{operator}-{order_id}'` (ej. `MRK-LEROY-83921`).

### 2.3 Cierre de Envío y Tracking
* **Endpoint:** `PUT /api/orders/{order_id}/tracking`
* Cuando Factusol genera el albarán de salida con el transportista y código de envío (GLS, SEUR, Correos Express), ERP Bridge envía el tracking a Mirakl, actualizando automáticamente el estado ante el cliente final y liberando el pago al vendedor.

## 3. Modelo de Configuración en ERP Bridge

```typescript
export interface MiraklConnectionConfig {
  operator: 'leroy_merlin' | 'pccomponentes' | 'carrefour' | 'mediamarkt' | 'decathlon' | 'custom';
  apiUrl: string;
  apiKey: string;
  defaultShippingDelayDays?: number;
  warehouseCode?: string; // Código de almacén de Factusol para filtrar stock
}
```

Este diseño convierte a ERP Bridge en un conector omnicanal con un esfuerzo de desarrollo mínimo y máxima captura de valor.
