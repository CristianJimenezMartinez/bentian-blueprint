# 304.1 - SimplyGest Connector
> **Estado:** Especificación Técnica Aprobada  
> **Tipo:** Conector de Entrada (ERP Local)  
> **Prioridad:** Fase 1 (Quick Win)

---

## 1. Propósito y Oportunidad de Mercado

**SimplyGest** es uno de los programas de gestión comercial y TPV de escritorio más extendidos en España (~35.000 clientes activos en retail, tiendas de telefonía, informática, recambios y pequeños distribuidores).

### El Dolor que Resuelve ERP Bridge:
El módulo oficial de sincronización e-commerce de SimplyGest (**WebLinker**) sufre dos problemas críticos:
1. **Coste elevado:** Cuota de suscripción de **40 €/mes** (~480 €/año).
2. **Arquitectura obsoleta y bloqueada:** WebLinker intenta conectar directamente desde el PC del cliente a la base de datos MySQL remota del hosting a través del **puerto 3306**. Prácticamente el 98% de los hostings españoles (SiteGround, Raiola, Webempresa, cPanel) bloquean el puerto 3306 por seguridad, generando continuas incidencias y caídas.

**ERP Bridge soluciona esto de raíz:** el Local Agent lee la base de datos de SimplyGest localmente y se comunica hacia la tienda online mediante llamadas salientes seguras HTTPS/REST, sin abrir puertos en el hosting ni en el router.

---

## 2. Ventaja Técnica: Reutilización del 90% del Código Existente

SimplyGest Desktop almacena sus datos en archivos **Microsoft Access (.MDB / Jet-ACE Engine)**.
* ERP Bridge ya dispone de un motor probado en producción: `packages/connectors/factusol/src/access-driver.ts` (basado en ADODB/OLEDB de Windows mediante script bridge VBS/WScript).
* **Desarrollo requerido:** No requiere programar ningún motor de base de datos nuevo. Solo se necesita implementar el mapeador específico de las tablas y campos de SimplyGest (`simplygest.connector.ts` y mappers).

## 3. Mapeo de Entidades y Base de Datos

### 3.1 Localización de Datos
El archivo de base de datos reside habitualmente en:
`C:\ProgramData\SimplyGest\Empresas\EmpresaX\Datos.mdb` (o en la carpeta de instalación).

### 3.2 Tabla de Artículos
| Campo SimplyGest | Tipo | Campo Canónico ERP Bridge | Descripción |
|---|---|---|---|
| `CODIGO` | Text | `sku` | Identificador único / SKU |
| `DESCR` | Text | `name` | Nombre del producto |
| `DESCR_LARGA` | Memo | `description` | Descripción detallada |
| `PRECIO_E` | Double | `price` | PVP base / Tarifa general |
| `PRECIO_C` | Double | `costPrice` | Precio de coste |
| `STOCK` | Double | `stockQuantity` | Existencias físicas en almacén |
| `IMPUESTO` | Integer | `taxClass` | Tipo de IVA aplicable |
| `FAMILIA` | Text | `categories` | Categoría o familia |
| `CODBARRAS` | Text | `barcode` | Código EAN / Código de barras |

### 3.3 Tabla de Clientes
| Campo SimplyGest | Tipo | Campo Canónico ERP Bridge | Descripción |
|---|---|---|---|
| `CODIGO` | Text | `id` | Código de cliente |
| `NOMBRE` | Text | `fiscalName` | Nombre fiscal o comercial |
| `CIF` | Text | `taxId` | NIF / CIF |
| `DIRECCION` | Text | `address.street` | Dirección postal |
| `CP` | Text | `address.postalCode` | Código postal |
| `POBLACION` | Text | `address.city` | Ciudad / Municipio |
| `PROVINCIA` | Text | `address.state` | Provincia |
| `EMAIL` | Text | `email` | Correo electrónico |
| `TELEFONO` | Text | `phone` | Teléfono de contacto |

### 3.4 Inserción de Pedidos
* Los pedidos procedentes de WooCommerce o PrestaShop se insertan en la tabla de presupuestos/pedidos de venta de SimplyGest con referencia externa `REFPEDIDO = 'WC-{order_id}'` dentro de una transacción atómica.

## 4. Plan de Validación y Pruebas Locales

1. **Descarga de Demo:** Descargar el instalador de evaluación completo desde `simplygest.es` (instalación desatendida en Windows con empresa de prueba).
2. **Inspección de Esquema:** Ejecutar una consulta de catálogo de tablas (`SHOW TABLES` / `MSysObjects`) utilizando el `AccessDriver` existente.
3. **Prueba Unitaria de Lectura:** Crear `packages/connectors/simplygest/test/read-products.spec.ts` verificando la extracción de 50 productos de demostración.
4. **Sincronización Piloto:** Ejecutar un flujo de sincronización hacia una tienda de prueba local en WooCommerce.
